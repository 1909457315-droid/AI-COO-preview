IAA 业务公式

D7 ROI 达成率 = 预估 D7 ROI / 目标 D7 ROI当前 106%，说明回收质量没有明显坏掉。
D7 预估毛利 = 预估 D7 收入 - 昨日投放成本当前 $42.8k，业务预估仍赚钱。

IAP D90+ 漏斗拆解

这一层把 IAP 归一化成订阅激活 -> 三日有效订阅 -> 付费 -> 当前有效订阅 -> D90+ 预估。

IAP 订阅漏斗

订阅激活：20包含免费试用和直接付费。直接付费用户也归一化为订阅激活。
三日有效订阅成本：$18.7成本口径正常，所以不立刻 Action。
直接付费：1 / 20结构偏弱，提示同渠道免费试用用户也可能质量偏差。
D1 取消率：高于近 7 日中位数进入 Watch，D3 扣费后确认。
Billing Retry：等待 D3如果大量进入计费重试，说明假量或支付能力风险更高。

IAP 回收可拆维度

推荐路径国家 -> 产品 -> 渠道 -> 账户 -> 广告计划 -> SKU / 支付页 -> 订阅漏斗。账户只在渠道存在账户层时出现。

交叉维度国家 x 产品、国家 x 渠道、渠道 x SKU、渠道 x 账户、SKU x 取消率、SKU x Billing Retry、优化师 x 计划。
